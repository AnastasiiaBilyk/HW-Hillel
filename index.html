Про себе

Вивчаю напрям тестування програмного забезпечення (QA). Знайома з принципами створення та підтримки тестової документації (тест-кейси, чек-листи, баг-репорти, тест-рани). Розумію основні рівні та види тестування: функціональне, регресійне, інтеграційне, smoke та exploratory testing. Маю базові знання роботи з системами управління тестуванням (Test Case Lab) та баг-трекінговими системами (Jira). Також володію SQL (BigQuery), що дозволяє проводити перевірку даних у базі, формувати запити для валідації. Використовую Python для простих сценаріїв автоматизації та аналізу. Знайома з аналітичними інструментами (Google Analytics 4, Tableau), що допомагає ширше бачити продукт та його якість.
